# __PROJECT__ Product Brief

## Target user

The sample starts with an authenticated author.

## Problem

The author needs to create and retrieve a post through one tested API journey.

## Primary v1 journey

An authenticated author creates a post and reads the stored result.

## Success measure

The deployed smoke test creates and reads one post without manual database work.

## Non-goals

- Publication workflow.
- Rich text editing.
- Multi-tenancy.

## Operating target

Run the API and PostgreSQL through Aspire during development. Select a deployment recipe before the first release.

## Data classification

The sample stores internal author identifiers and public post titles.
